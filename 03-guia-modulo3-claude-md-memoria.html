🧠 ¿Qué es CLAUDE.md?

El concepto más importante para trabajar de forma profesional con Claude Code

💡
Definición simple: CLAUDE.md es un archivo de texto en formato Markdown (lenguaje de escritura simple con formato) que Claude Code lee automáticamente cada vez que arranca en una carpeta. Es la memoria permanente del proyecto — le dice quién eres, cómo trabajas y qué reglas debe seguir siempre.

❌ Sin CLAUDE.md

  • Claude Code empieza desde cero cada vez
  • No sabe que eres de MarketingMo
  • No conoce a tus clientes
  • No sabe qué agentes tienes
  • Tienes que explicarlo todo siempre
  • Respuestas genéricas sin contexto

✅ Con CLAUDE.md

  • Arranca con contexto completo
  • Sabe que eres MarketingMo
  • Conoce tus 12 clientes activos
  • Sabe qué son B.A.C., A.D.M. y A.C.I.
  • Nunca tienes que repetir nada
  • Respuestas personalizadas desde el minuto 1
🎯
La analogía perfecta: Es el manual de instrucciones que le das a un empleado nuevo el primer día. No tienes que explicarle las mismas cosas cada vez que llega — ya las sabe porque las tiene escritas. El empleado nuevo es Claude Code. El manual eres tú escribiéndolo.

⚙️ Cómo lo usa Claude Code

El proceso exacto desde que escribes "claude" hasta que empieza a trabajar

PasoQué hace Claude Code
1. ArrancaEjecutas claude en PowerShell
2. Detecta carpetaIdentifica en qué carpeta estás — en tu caso claudecode-practicas
3. Busca CLAUDE.mdRecorre la carpeta y las carpetas superiores buscando archivos CLAUDE.md
4. Lee todos los que encuentraLos carga todos en su contexto — de más específico a más general
5. Arranca con ese contextoYa sabe todo lo que pusiste en CLAUDE.md antes de que escribas nada
🔍
¿Cómo verificarlo? En este módulo lo comprobaste tú mismo. Cerraste Claude Code y lo reabriste. Sin decirle nada, le preguntaste "¿qué clientes tengo activos?" y él te presentó los 12 clientes en una tabla perfecta. Eso es la memoria en acción.

Dónde puedes poner el CLAUDE.md y qué prioridad tiene cada uno

🌍
~/.claude/CLAUDE.md Global personal
Se aplica a TODOS tus proyectos en cualquier carpeta. Aquí pones información sobre ti que siempre aplica: tu nombre, idioma preferido, estilo de trabajo.
📁
C:\Users\elias\claudecode-practicas\CLAUDE.md Tu proyecto actual ✓
El que creaste hoy. Se aplica solo cuando Claude Code está dentro de esta carpeta. Es el más común y el que usarás para cada proyecto.
📂
C:\Users\elias\claudecode-practicas\clientes\CLAUDE.md Subcarpeta
Se carga automáticamente cuando Claude Code lee archivos dentro de esa subcarpeta. Útil para instrucciones específicas de una sección del proyecto.
🔒
C:\Users\elias\claudecode-practicas\CLAUDE.local.md Personal privado
Versión privada del CLAUDE.md del proyecto. No se sube a Git (se ignora automáticamente). Para notas personales que no quieres compartir con el equipo.

Prioridad — ¿cuál gana si hay conflicto?

⚖️
Más específico gana. CLAUDE.md de subcarpeta > CLAUDE.md de proyecto > CLAUDE.md global. Pero no se cancelan entre sí — se combinan. Claude Code los carga todos y los aplica juntos.

✨ Cómo crearlo con /init

El método automático que usaste en este módulo

💡
¿Qué hace /init? Claude Code analiza el contenido de tu carpeta — archivos, subcarpetas, tipos de archivo — y genera automáticamente un CLAUDE.md con lo que encontró. Es el punto de partida. Luego tú lo personalizas.
# Paso 1: Entrar en la carpeta del proyecto cd C:\Users\elias\claudecode-practicas claude # Paso 2: Dentro de Claude Code, ejecutar /init /init # Resultado: Claude Code analiza la carpeta y te propone un CLAUDE.md Create file: CLAUDE.md → Detectó: prueba.txt, carpeta clientes/, ideas-pasteleria.md → Generó descripción automática del workspace # Paso 3: Confirmar creación Seleccionar opción 2 → "Yes, allow all edits during this session"
⚠️
El /init es solo el punto de partida. Lo que genera automáticamente es básico y en inglés. Siempre debes personalizarlo después con tu información real: agencia, clientes, agentes, reglas de trabajo. Eso fue lo que hiciste tú en este módulo.

📝 Estructura y sintaxis del CLAUDE.md

Cómo está escrito y qué significa cada símbolo

📄
¿Qué es Markdown? Markdown (MD) es un lenguaje de escritura simple que usa símbolos para dar formato al texto. No necesitas saber programación — son convenciones simples que cualquier persona puede aprender en 5 minutos.
# Título principal (un solo #)
## Sección (dos ##)
### Subsección (tres ###)
**Texto en negrita** — rodea con doble asterisco
- Item de lista — guión al inicio
- Así se ve un item de lista en el archivo
- Otro item de la lista
`código inline` — rodea con comillas invertidas
--- (tres guiones = separador horizontal)

Qué NO incluir

❌
Nunca pongas en el CLAUDE.md: contraseñas, API keys, tokens de acceso, datos bancarios, números de tarjeta ni información confidencial de clientes. El CLAUDE.md se carga en el contexto de Claude Code y se envía a los servidores de Anthropic con cada mensaje.

🚫 Qué NO hacer con el CLAUDE.md

Errores que debes evitar para proteger tu trabajo y tu privacidad

❌
NUNCA guardes credenciales en el CLAUDE.md. Contraseñas, API keys (llaves de acceso a servicios), tokens (códigos de autenticación), datos de tarjetas ni accesos a cuentas de clientes. El CLAUDE.md se envía a los servidores de Anthropic con cada petición.
❌
NUNCA pongas información confidencial de clientes sin su permiso. Datos personales, contratos, precios acordados o estrategias privadas no deben estar en el CLAUDE.md. Usa referencias genéricas en su lugar.
❌
NUNCA hagas el CLAUDE.md demasiado largo. Si supera las 200 líneas empieza a perder efectividad — Claude Code tiene un límite de contexto (cantidad de información que puede procesar a la vez). Sé conciso y directo. Cada línea debe aportar valor.
⚠️
Cuidado con instrucciones contradictorias. Si tienes CLAUDE.md en la carpeta raíz y otro en una subcarpeta con instrucciones opuestas, puede confundir a Claude Code. Mantén coherencia entre todos los niveles.
⚠️
Actualiza el CLAUDE.md cuando cambien tus clientes. Si pierdes un cliente, cambia su plan o añades uno nuevo, actualiza el CLAUDE.md inmediatamente. La información desactualizada genera respuestas incorrectas.
