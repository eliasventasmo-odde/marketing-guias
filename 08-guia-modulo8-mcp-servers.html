🔌 Qué es MCP

El protocolo que convierte Claude Code en un hub de integraciones

💡
MCP (Model Context Protocol) es el estándar abierto que permite a Claude Code conectarse con servicios externos. Funciona como los enchufes de tu casa — cualquier servicio que implemente el estándar MCP se conecta y Claude Code puede usarlo directamente desde el terminal.
🎯
La analogía perfecta: Antes de MCP, Claude Code era un ordenador sin conexión a internet — muy capaz pero aislado. Con MCP es un hub conectado a todos tus servicios. Le preguntas sobre Notion y lo ve. Le pides que escriba en Gmail y lo hace. Todo desde el terminal sin abrir ninguna app.

Cómo ver tus MCP servers activos

# Dentro de Claude Code: /mcp # Muestra todos los servidores y su estado de conexión # Desde PowerShell: ! claude mcp list # Lista todos los servidores con su URL y estado

🔐 Seguridad — gestión de tokens

Las reglas de oro para manejar credenciales de MCP servers

⚠️ Lección aprendida hoy — con GitHub
❌
NUNCA publiques un token en el chat. En esta sesión el token de GitHub apareció en el output del terminal y fue visible. Se revocó inmediatamente y se creó uno nuevo. Los tokens son contraseñas — si alguien los ve puede acceder a tu cuenta.
✅
Siempre pasa el token directamente dentro de Claude Code, no en este chat. Escribe el comando en el prompt > del terminal para que no quede registrado aquí.
✅
Rota los tokens periódicamente. Ve a github.com/settings/tokens cada 3–6 meses, revoca el token antiguo y crea uno nuevo.

Reglas de seguridad para tokens MCP

❌
NUNCA escribas un token en este chat. El historial del chat puede ser visto. Todos los tokens van directamente en el terminal de Claude Code o en variables de entorno del settings.json.
❌
NUNCA uses "No expiration" en tokens de producción. En la práctica lo hiciste para simplificar — pero en un entorno profesional real, los tokens deben tener expiración de 90 días máximo.
✅
Usa permisos mínimos necesarios. Para GitHub solo necesitas repo, read:user y notifications. No actives permisos de admin, org o billing que no necesitas.
✅
Si un token se expone — revócalo inmediatamente. Ve a la página de tokens del servicio y bórralo. Créa uno nuevo. El proceso tarda menos de 2 minutos.
