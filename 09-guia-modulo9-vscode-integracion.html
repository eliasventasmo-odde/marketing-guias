💻 Qué es VS Code y para qué sirve

El editor que convierte el trabajo invisible del terminal en algo visible

💡
Definición simple: VS Code (Visual Studio Code) es un editor de texto avanzado creado por Microsoft. Es gratuito y se usa para ver, editar y gestionar archivos de cualquier tipo — Markdown, JSON, código, scripts. Con la extensión de Claude Code instalada, se convierte en el panel visual de todo lo que hace el terminal.

La diferencia entre trabajar con y sin VS Code

🖥️ Solo con terminal
Claude Code modifica archivos
No ves qué cambió exactamente
Tienes que abrir el archivo manualmente
Editas desde línea de comandos
Sin resaltado de sintaxis
💻 Terminal + VS Code
Claude Code modifica archivos
VS Code muestra el cambio en tiempo real
Ves exactamente qué líneas cambiaron
Editas haciendo clic y escribiendo
Colores y formato automático
🎯
Para MarketingMo: VS Code es donde lees y editas los briefs de clientes, los prompts de tus agentes, los informes ADM y el CLAUDE.md. El terminal es donde Claude Code trabaja. VS Code es donde tú revisas y ajustas.

🔗 Cómo conectar VS Code con Claude Code

El proceso completo que seguiste hoy — documentado para repetirlo

Paso 1 — Instalar la extensión oficial

# En VS Code: Ctrl+Shift+X → buscar "Claude Code" → instalar la de Anthropic (7.9M descargas) # Confirmar: "Trust Publisher & Install"

Paso 2 — Abrir VS Code en tu carpeta de trabajo

# Opción A — Desde el terminal de Claude Code: code ← escribe "code" en el prompt > y Claude Code abre VS Code en la carpeta actual # Opción B — Desde PowerShell: cd C:\Users\elias\claudecode-practicas code . ← el punto significa "abrir esta carpeta" # Opción C — Desde VS Code manualmente: Archivo → Abrir carpeta → seleccionar claudecode-practicas

Paso 3 — Conectar el terminal con VS Code

# Dentro de Claude Code (terminal): /ide # Seleccionar "Visual Studio Code" # Aparece: "Connected to Visual Studio Code"
✅
Verificación: En el terminal aparece Connected to Visual Studio Code y en VS Code se abre el panel CHAT en la barra derecha. Los dos están sincronizados — lo que hace Claude Code en el terminal se refleja en VS Code.
⚠️
Importante: La conexión /ide hay que hacerla en cada sesión nueva. No es permanente. Pero puedes activar la auto-conexión escribiendo en Claude Code: "Activa la auto-conexión al IDE en mi configuración".

✏️ Cómo modificar cualquier archivo

Los tres métodos para editar — con ejemplos concretos

Método 1 — Editar directamente en VS Code (más rápido para cambios pequeños)

✅
Cuándo usarlo: Para cambios pequeños y puntuales — corregir un dato de un cliente, añadir una nota, cambiar un precio, actualizar un plan de servicio.
# Proceso: 1. En VS Code, haz clic en el archivo en el panel izquierdo 2. El archivo se abre en el editor central 3. Haz clic donde quieres editar 4. Escribe el cambio 5. Ctrl+S para guardar # Ejemplo — cambiar el plan de La Tiendologia en CLAUDE.md: Clic en CLAUDE.md → buscar "La Tiendologia" → cambiar "Plan: Básico" a "Plan: Crecimiento" → Ctrl+S

Método 2 — Pedir el cambio a Claude Code (mejor para cambios complejos)

✅
Cuándo usarlo: Para cambios que implican lógica, múltiples archivos o cuando no sabes exactamente dónde está lo que quieres cambiar.
# En el terminal de Claude Code: "Actualiza en el CLAUDE.md el plan de La Tiendologia a Plan Crecimiento" "Añade un nuevo cliente al CLAUDE.md: Restaurante El Rincón, sector hostelería, Plan Básico" "Cambia en todos los archivos de clientes la fecha de creación de marzo a abril 2026"

Método 3 — Usar Ctrl+H para buscar y reemplazar en VS Code

✅
Cuándo usarlo: Para cambiar la misma palabra en múltiples partes de un archivo. Por ejemplo, cambiar "Mónico" por "Elias" en todo el documento de una vez.
# Proceso con Ctrl+H: 1. Ctrl+H → se abre el panel de buscar/reemplazar 2. En "Buscar" escribe el texto actual 3. En "Reemplazar" escribe el texto nuevo 4. "Reemplazar todo" para cambiarlo de golpe 5. Ctrl+S para guardar

🤖 Cómo modificar los agentes B.A.C., A.D.M. y A.C.I.

Tus agentes son archivos — puedes editarlos cuando quieras desde VS Code

💡
Clave importante: Tus agentes viven en dos lugares — sus prompts maestros en Notion, y sus slash commands en .claude/commands/. Puedes modificar los slash commands directamente desde VS Code en cualquier momento. Los cambios aplican en la siguiente sesión de Claude Code.
📋
Agente B.A.C. — Briefing · Acción · Contenido
.claude/commands/brief-cliente.md

Puedes modificar en VS Code: el número de bloques del brief, las preguntas de cada bloque, el tono de las instrucciones, el formato del documento generado, añadir nuevas secciones.

# Para modificarlo en VS Code: 1. Panel izquierdo → .claude → commands → brief-cliente.md 2. Clic para abrir el archivo 3. Edita el contenido entre los --- y --- 4. Ctrl+S para guardar 5. Reinicia Claude Code para que detecte el cambio # Ejemplo de modificación — añadir bloque de redes sociales: Abre brief-cliente.md → después del Bloque 5 añade: ## BLOQUE 6 — REDES SOCIALES ACTUALES - ¿Qué redes tiene activas? - ¿Con qué frecuencia publica? - ¿Cuál es su red principal?
📊
Agente A.D.M. — Auditoría de Métricas
.claude/commands/informe-adm.md

Puedes modificar en VS Code: las tablas de métricas, los benchmarks de cada plan, las secciones del informe, las recomendaciones automáticas, el formato de exportación a Notion.

# Ejemplo de modificación — añadir métricas de TikTok: Abre informe-adm.md → después de la sección Facebook añade: ## 📱 MÉTRICAS TIKTOK (si aplica) | Métrica | Valor actual | Mes anterior | Variación | |---|---|---|---| | Seguidores | | | | | Vídeos publicados | | | | | Views totales | | | | | Engagement rate | | | |
🔍
Agente A.C.I. — Auditoría de Cliente Inicial
.claude/commands/auditoria-aci.md

Puedes modificar en VS Code: las 9 secciones de la auditoría, los criterios de evaluación, los planes recomendados, la puntuación del diagnóstico, el formato del baseline Día 0.

# Ejemplo de modificación — añadir puntuación al diagnóstico: Abre auditoria-aci.md → en la Sección 6 añade: ## 🎯 PUNTUACIÓN DIGITAL (0-100) | Área | Puntos (máx 20) | |---|---| | Presencia web | | | Instagram | | | Facebook | | | Contenido y consistencia | | | Posicionamiento local | | | **TOTAL** | **/100** |
⚠️
Recuerda siempre: Después de modificar un slash command en VS Code hay que reiniciar Claude Code para que detecte el cambio. Escribe /exit y vuelve a abrir con claude.

📚 La mejor forma de aprender todo esto

El método que maximiza la retención y la aplicación práctica

💡
La verdad sobre el aprendizaje técnico: No se aprende leyendo — se aprende haciendo. Estas guías son tu referencia, no tu escuela. La escuela es el trabajo diario con tus clientes reales usando Claude Code.
🎓 Plan de consolidación — 4 semanas
1
Semana 1 — Rutina básica diaria
Usa Claude Code todos los días aunque sea 15 minutos. Abre la carpeta, conecta VS Code y haz una tarea pequeña — actualizar un cliente, revisar el CLAUDE.md, leer el log.txt.
→ Objetivo: que el arranque diario sea automático sin mirar la guía
2
Semana 2 — Integrar con clientes reales
Usa /brief-cliente con un cliente nuevo real. Usa /informe-adm con el export de Metricool de un cliente activo. Envía el informe a Notion. Comprueba que funciona.
→ Objetivo: completar el flujo completo Metricool → Claude Code → Notion una vez
3
Semana 3 — Personalizar y mejorar
Modifica los slash commands según lo que veas que falta. Añade un nuevo bloque al brief del Agente B.A.C. Prueba un skill nuevo (@competitive-analysis con un cliente). Crea un comando nuevo.
→ Objetivo: que el sistema sea tuyo, no una copia de lo que aprendiste
4
Semana 4 — Automatizar lo repetitivo
Identifica qué haces manualmente cada semana que podrías automatizar. Crea un nuevo hook. Añade un skill a tu workflow. Conecta otro MCP server si lo necesitas.
→ Objetivo: tener al menos 3 procesos de la agencia automatizados con Claude Code

Los 3 errores más comunes al principio

❌
Error 1 — Querer usarlo todo de golpe. Claude Code tiene muchas funciones. No necesitas usar hooks, MCP servers, skills y slash commands el primer día. Empieza con lo básico — abrir, hacer una tarea, cerrar. Lo demás llega solo con la práctica.
❌
Error 2 — No guardar con Ctrl+S después de editar en VS Code. Si editas un archivo en VS Code y no guardas, Claude Code sigue viendo la versión anterior. Siempre Ctrl+S después de cualquier cambio manual.
❌
Error 3 — Olvidar reiniciar Claude Code después de cambiar un slash command. Si modificas brief-cliente.md en VS Code y ejecutas /brief-cliente sin reiniciar, usará la versión antigua. Siempre /exit + claude después de editar commands.
