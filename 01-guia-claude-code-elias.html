🤖 ¿Qué es Claude Code?

Entiende la diferencia antes de usarlo

💡
Definición simple: Claude Code es un agente de inteligencia artificial que vive en tu terminal (línea de comandos). A diferencia de Claude.ai (el chat web que usas normalmente), Claude Code puede leer tus archivos, editarlos, crear carpetas, ejecutar programas y gestionar tu código — todo desde la consola, sin que tú hagas nada manualmente.
CaracterísticaClaude.ai (chat web)Claude Code (terminal)
¿Dónde vive?Navegador web / AppTerminal (PowerShell)
¿Puede leer tus archivos?✗ No✓ Sí
¿Puede editar archivos?✗ No✓ Sí
¿Puede ejecutar comandos?✗ No✓ Sí
¿Trabaja con proyectos reales?✗ No✓ Sí
¿Necesita Internet?✓ Sí✓ Sí
Cuenta necesariaClaude.aiClaude.ai (misma cuenta)
✅
Tu caso de uso: Con Claude Code puedes decirle "crea los archivos del agente B.A.C.", "organiza los prompts de MarketingMo", "revisa este código de n8n" — y él lo hace directamente en tu ordenador, sin copiar y pegar manualmente.

🌅 Cómo arrancar Claude Code cada día

El flujo exacto desde que abres el ordenador hasta que estás trabajando

💡
Concepto clave: Claude Code siempre trabaja dentro de una carpeta. Antes de abrirlo, debes navegar a la carpeta del proyecto en el que vas a trabajar. Es como decirle "trabaja en este escritorio, no en cualquier sitio de la casa".

🗂️ Tus carpetas de trabajo

C:\Users\elias\claudecode-practicas → Para aprender y practicar
C:\Users\elias\[carpeta-agente] → Para proyectos reales de MarketingMo

Flujo de arranque diario

1️⃣
Abre PowerShell
Menú Inicio → busca "PowerShell" → clic derecho → "Ejecutar como administrador" (opcional pero recomendado)
↓
2️⃣
Navega a tu carpeta de proyecto
# Para prácticas:
cd C:\Users\elias\claudecode-practicas

# Para proyectos reales (sustituye por tu ruta):
cd C:\Users\elias\[nombre-de-tu-proyecto]
cd = Change Directory = Cambiar directorio. Le dice a la terminal en qué carpeta quieres estar.
↓
3️⃣
Abre Claude Code
claude
Verás "Welcome back Elias!" con tu cuenta Pro activa y la ruta de tu carpeta. ¡Listo para trabajar!
↓
4️⃣
Empieza a trabajar — escribe en lenguaje natural
# Ejemplos de lo que puedes escribir:
Crea un archivo con el prompt del agente BAC
Organiza todos los archivos .md en una carpeta llamada prompts
Revisa el archivo settings.json y dime si hay errores

Para cerrar Claude Code

/exit
# O simplemente cierra la ventana de PowerShell
✅
Tu sesión se guarda automáticamente. La próxima vez que abras Claude Code recordará las conversaciones recientes. Puedes retomar con claude -c (continue = continuar última sesión).

🚀 Primeros pasos en un proyecto nuevo

Lo primero que debes hacer cuando entras a una carpeta por primera vez

El comando /init — El briefing del proyecto

📄
/init crea automáticamente un archivo llamado CLAUDE.md en tu carpeta. Este archivo es la "memoria permanente" del proyecto — Claude Code lo lee cada vez que arrancas y sabe exactamente con qué está trabajando. Es como darle un briefing completo a un empleado nuevo antes de que empiece.
# Dentro de Claude Code, en el prompt >, escribe:
/init
# Claude Code analiza tu carpeta y crea el CLAUDE.md automáticamente

Dónde se guarda el CLAUDE.md

C:\Users\elias\[tu-proyecto]\CLAUDE.md

Puedes editar este archivo manualmente con VS Code para añadir:

  • Qué tipo de proyecto es (agencia, SaaS, cliente X...)
  • Comandos específicos del proyecto
  • Convenciones de nombres de archivos
  • Información del cliente o del negocio
# Ejemplo de CLAUDE.md para MarketingMo:
# Proyecto: Agente BAC - MarketingMo
Agencia de marketing digital en España
Sistema: B.A.C. (Briefing · Acción · Contenido)

## Estructura
- /prompts → Prompts de los agentes
- /clientes → Carpetas por cliente
- /plantillas → Templates reutilizables

⌨️ Comandos esenciales

Los slash commands más útiles para tu día a día

💡
¿Qué es un slash command? Son comandos especiales que empiezan con / y activan funciones específicas de Claude Code. No son peticiones en lenguaje natural — son instrucciones directas al sistema.
/help Muestra todos los comandos disponibles y atajos de teclado
/init Crea el archivo CLAUDE.md con la memoria del proyecto
/clear Limpia el historial de conversación (libera contexto)
/exit Cierra Claude Code y vuelve a PowerShell
/model Cambia el modelo de IA (sonnet, opus, haiku)
/memory Edita los archivos de memoria CLAUDE.md
/status Muestra versión, modelo activo y configuración
/cost Muestra el uso de tokens y coste de la sesión
/review Revisión de código de los últimos cambios
/compact Comprime el historial cuando se llena el contexto

🚫 Qué NO debes hacer

Errores comunes que debes evitar para proteger tu trabajo

❌
NUNCA uses Claude Code en la carpeta raíz del sistema. Si lo abres desde C:\ o C:\Windows, puede tener acceso a archivos del sistema operativo. Siempre trabaja en carpetas específicas de tus proyectos.
❌
NUNCA uses --dangerously-skip-permissions en tu ordenador personal. Este flag omite todos los avisos de seguridad y puede modificar o eliminar archivos sin pedirte confirmación. Solo es para servidores aislados y entornos de prueba.
❌
NUNCA guardes contraseñas, API keys o datos sensibles en el CLAUDE.md. Este archivo puede ser leído por Claude Code y enviado como contexto. Guarda las credenciales en variables de entorno o en archivos .env separados.
❌
NUNCA interrumpas Claude Code a la mitad de una edición de archivos. Si está modificando múltiples archivos y lo cierras, puede dejar archivos a medias. Usa Ctrl+C para interrumpir limpiamente y espera a que confirme.
⚠️
Siempre revisa los cambios antes de confirmar. Claude Code te pide permiso antes de modificar archivos (modo por defecto). Léelos antes de aceptar. Si algo no te parece bien, di "no" o "deshaz el último cambio".
